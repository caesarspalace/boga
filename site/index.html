Potencia y Precisión Jurídica

Funcionalidades Avanzadas v2.0

Diseñado específicamente para cubrir las exigencias complejas de la redacción notarial moderna.

📝

Sustitución Dinámica

Reemplazo inteligente de etiquetas ${VARIABLE} en todo el documento manteniendo intactas las negritas, fuentes y estilos originales.

🔀

Lógica Condicional Avanzada

Inclusión de bloques opcionales mediante directivas ${#if} / ${/if} que eliminan párrafos vacíos si la condición no se cumple.

✒️

Transformadores Notariales

Modificadores integrados como :letras para montos, formato de fechas en extenso con :extenso, y CUIT/DNI con puntos automáticos.

📊

Procesamiento Masivo CSV

Automatice la producción en cadena de decenas de escrituras individuales leyendo orígenes tabulares estructurados en formato CSV.

💻

Interfaz JavaFX

Aplicación de escritorio multiplataforma con interfaz gráfica moderna, intuitiva y optimizada para el trabajo diario de escribanías.

🛡️

Privacidad Absoluta

Funcionamiento 100% local en su equipo. Sus documentos y datos sensibles de clientes nunca se exponen en nubes de terceros.

Ingeniería de Software

Arquitectura Robusta y Segura

El software ha sido diseñado bajo los más altos estándares de desarrollo por Adrian Tabak. Su estructura modular garantiza un rendimiento fluido, bajo consumo de recursos y alta estabilidad.

  • ✓ Stack Tecnológico: Java 19+, Apache POI para manipulación nativa de OpenXML (.docx), y JavaFX para interfaz gráfica.
  • ✓ Motor XML Local: Análisis sintáctico optimizado que opera directamente sobre la estructura interna del documento sin requerir servidores externos.
  • ✓ Configuración de Directorio: Compatible con entornos seguros utilizando el directorio de trabajo raíz en $HOME / %USERPROFILE%.

Especificaciones Técnicas

Core Engine: Java Virtual Machine 19+
Document Parser: Apache POI XWPF
UI Framework: JavaFX Controls & FXML
